How It Works

Four steps from voice to text, in under two seconds.

🎤 Microphone
→
🧠 Whisper STT
→
✨ LLM Refine
→
📋 Auto-Paste

Hold the Hotkey

Press and hold Ctrl+Shift+Space (configurable) to start recording. A waveform appears so you can see your audio level.

Speak Naturally

Talk at your normal pace. Voice Flow captures 16 kHz audio and monitors silence for auto-stop in wake-word mode.

AI Refines

The raw transcript passes through your chosen LLM — Ollama, Groq, OpenAI, or any compatible API — to fix grammar, rephrase for email, or format as bullet points.

Text Appears

The polished text is copied to your clipboard and pasted automatically (Ctrl+V / Cmd+V) right where your cursor sits. Done.

Features

Everything you need for voice-driven productivity — no cloud account required for transcription.

🎤

Push-to-Talk & Wake Word

Hold a hotkey to record, or say "Hey Jarvis" for hands-free activation with automatic silence detection.

🧠

Local Whisper STT

Transcription runs entirely on your machine via OpenAI Whisper. Supports tiny → large models and 14+ languages.

✨

LLM Refinement

Send raw transcripts through Ollama, Groq, OpenAI, LM Studio, or any compatible endpoint for grammar fixes, rephrasing, or formatting.

🎯

Task Profiles

Choose your task on startup — Prompting, Coding, Email, Notes, Meeting, or General — and the app auto-configures its behavior.

📋

Smart Paste

Auto-pastes where your cursor is. Typing mode for apps that block Ctrl+V. Re-paste with Ctrl+Shift+R. Clipboard templates via {clipboard}.

📊

Live Waveform

Real-time audio level visualization while recording so you know the mic is picking you up.

📂

History & Favorites

Full-text search, date range filters, favorites, export to .txt/.md — all in a built-in history viewer.

🔊

Sound Feedback

Audible beeps on record start, stop, cancel, and paste so you always know the state — even without looking.

⚙️

System Tray Control

Toggle every setting from the tray menu — LLM, wake-word, mode, task, language, typing mode, waveform, and more.

🔄

Context-Aware Refine

Sends the previous transcript as context so follow-up dictations produce coherent, connected text.

📝

Editable Prompts

Edit mode prompts directly in Settings — no JSON files needed. Each mode's system prompt is fully customizable.

🚀

Launch on Startup

One-click toggle registers Voice Flow in Windows startup (HKCU\Run). Cross-platform paste on macOS.

Refinement Modes

Switch modes from the tray menu or Settings. Each mode sends a different system prompt to the LLM.

Mode What it does
Default Fix grammar and clean up the transcript. Return only the cleaned text.
Email Rewrite as a professional email body with greeting and sign-off.
Code Comment Rewrite as a concise, technical code comment.
Bullets Convert into a tight bulleted list — one idea per bullet.
Meeting Notes Summarize into Decisions and Action Items sections.

Quick Start

Get running in under a minute.

# Clone the repo git clone https://github.com/your-username/voiceflow.git cd voiceflow # Install dependencies pip install -r requirements.txt # Run python main.py

Requirements: Python 3.10+, a microphone, ~1 GB disk for Whisper base model.
Optional: Ollama running locally for LLM refinement, or a Groq / OpenAI API key.

Keyboard Shortcuts

Ctrl+Shift+Space Hold to record
Escape Cancel recording
Ctrl+Shift+R Re-paste last result
