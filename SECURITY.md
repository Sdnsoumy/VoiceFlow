# Security Policy

## Supported versions

Security fixes are made against the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private security advisory workflow for this repository, or contact the
maintainer privately through the GitHub profile at
https://github.com/Sdnsoumy.

Include the affected version, reproduction steps, impact, and any suggested
fix. Please allow time for investigation before publicly disclosing the issue.
